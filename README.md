## Project Description

This lab explores the **Bias-Variance Tradeoff** and demonstrates how model complexity affects machine learning performance.

A synthetic dataset based on a sine wave with added noise is used to visualize the concepts of:

- Underfitting
- Overfitting
- High Bias
- High Variance
- Model Generalization
